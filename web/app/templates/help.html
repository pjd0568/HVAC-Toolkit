How the app works

A toolkit of independent HVAC design calculators. Pick a tool from the left-hand navigation, enter your design figures, and read the results. A few things work the same way across every tool — worth knowing once.

Units — SI or Imperial, everywhere at once

The SI · Metric / IP · Imperial toggle in the top bar sets the unit system for the whole app in one click. Every input label, every result and every chart axis switches with it. Imperial conventions used here: duty in Btu/h, humidity ratio in grains/lb, pressure in inHg, plus °F, CFM, lb/h and ft³/lb. Set it before you start typing so you enter values in the units you're thinking in.

Memory Slots — carry a condition between tools

The three Memory Slots in the bar below the top bar are shown on every page. When the weather lookup ships, you will be able to copy a design condition into a slot from that tool. Until then, you can still paste a slot into any psychrometric tool’s airstream if a slot is filled — Clear a slot with the × on its chip.

Every result is a shareable link

Tool results live in the page's web address. Copy the URL after a calculation and it reopens with the same inputs and answer — handy for saving a case, sending it to a colleague, or bookmarking a standard scenario.

PDF report & PNG chart export

Once a psychrometric or duct calculation succeeds, a Download PDF Report panel appears under the results. Fill in the Project / System / Revision / Author fields and download a formatted report with the inputs, results and chart. Where there's a chart, an Export Chart (PNG) button gives you just the image. Reports are generated from the same calculation as the screen, so they can never disagree with it.

New here? Start with Psychrometrics — Single Point to resolve a moist-air state, or open Weather & Design Conditions for the planned ASHRAE lookup and links to ASHRAE’s own tools.

Account, billing & cancel

How trials, the £9.50/month subscription, invoices, and cancellation work — without a separate billing portal inside the app.

Trial and subscribe

  1. New accounts get a 14-day free trial of the full calculator suite.
  2. When you’re ready to continue, open Pricing and complete Stripe’s secure checkout (card; tax for your location is calculated there).
  3. After payment, suite access stays unlocked. You’ll also get a confirmation email from us when the subscription becomes active.

Invoices and receipts

Payments are processed by Stripe (Managed Payments). Receipts and invoices are sent by Stripe / Link to the email you used at checkout — open those messages to download a PDF or review past charges. We don’t host an invoice history page in the app.

Cancel or change payment details

There is no in-app “cancel subscription” button. Manage or cancel through Stripe / Link:

  1. Find a subscription receipt or invoice email from Stripe / Link for this product.
  2. Use the links in that email to open the customer billing area (often via Link), update the card, or cancel the subscription.
  3. Cancellation takes effect at the end of the current paid period (see Terms). When the subscription ends, suite access locks and we’ll send a short confirmation email.
If you can’t find the Stripe / Link email, contact us with topic Billing (below) and we can help from the Stripe Dashboard.

Billing or account support

Use Contact and choose topic Billing (or Help / Bug for other issues). Include the email on your account. For refunds and account closure requests, the same form is the right starting point — see also the Terms and Privacy pages.

Psychrometrics — Single Point

Psychrometrics Resolve the complete state of moist air from any two of its properties. Enter a dry-bulb temperature and one more property; get every other property back.

When to use it

Any time you have a partial description of an air condition and need the rest — for example you know dry-bulb and RH and want the wet-bulb, dew point, enthalpy or moisture content. It's the building block behind the other psychrometric tools.

Inputs

Altitude
Site elevation. The Barometric Pressure beside it is derived automatically (standard atmosphere) and is read-only — psychrometric properties depend on pressure, so this keeps them correct for the site. At sea level leave it at 0.
State Dry Bulb
The dry-bulb (ordinary thermometer) temperature.
State Second Property
Which second property you're providing: Relative humidity (%), Wet bulb, Moisture ratio, or Dew point.
State Second Value
The value of whichever second property you selected.

How to use it

  1. Set the site Altitude (or leave 0 for sea level).
  2. Enter the Dry Bulb temperature.
  3. Choose the Second Property and enter its value.
  4. Press Calculate. The full state is listed and plotted on the psychrometric chart.

Reading the results

You get dry-bulb, wet-bulb, dew point, relative humidity, humidity ratio, specific enthalpy, specific volume, density and vapour pressure — plus the point marked on the chart. "— (dry air)" for dew point means the air is so dry the dew point is below the model's floor.

Psychrometrics — Mixed Air

Psychrometrics Mix two airstreams and find the resulting condition. The classic case is blending fresh outdoor air with recirculated return air ahead of a coil.

When to use it

To find the on-coil condition after outdoor and return air combine, or any time two flows at different conditions meet. The mix is weighted by the mass flow of each stream.

Inputs

Site Conditions
Altitude → derived barometric pressure, as in Single Point.
Stream A / Stream B — Dry Bulb, Second Property, Second Value
The condition of each airstream, entered the same way as a single point.
Stream A / Stream B — Flow
The volume flow rate of each stream. The proportions set the weighting of the mix.

How to use it

  1. Set the site Altitude.
  2. Enter Stream A's condition and flow (e.g. outdoor air).
  3. Enter Stream B's condition and flow (e.g. return air).
  4. Press Calculate — the mixed condition appears as a third row and on the chart between the two inputs.

Reading the results

The table shows both inputs and the mixed state, with each stream's dry-air mass flow. If the mix would fall in the fog region (super-saturated), the tool settles it onto the saturation curve and reports the resulting condensate — a warning banner flags this.

Psychrometrics — Cooling Coil

Psychrometrics Enter air-on, apparatus dew point and off-coil dry bulb. The coil locks moisture to the ON→ADP chord and reports duty, leaving RH, condensate and contact/bypass factor.

When to use it

To size or check a chilled-water or DX cooling coil once you know the entering air and the coil surface temperature (ADP), and you have chosen how cold the air should leave.

Inputs

Site Conditions
Altitude → derived barometric pressure.
On-coil — Dry Bulb, Second Property, Second Value
The air condition entering the coil (often the mixed-air result).
On-coil Flow
The volume flow through the coil.
Apparatus Dew Point
Mean coil surface temperature on the saturation curve — sets the process chord with air-on.
Off-coil Dry Bulb
How far along that chord the air travels before leaving. Leaving moisture and RH are calculated, not entered.

How to use it

  1. Set the site Altitude.
  2. Enter the On-coil condition and flow.
  3. Enter the Apparatus Dew Point and Off-coil Dry Bulb.
  4. Press Calculate. Read the duty table and the ON→ADP chord on the chart, and expand Coil application notes for selection guidance.

Reading the results

Total / sensible / latent cooling
The heat removed, split into the part that lowers temperature (sensible) and the part that removes moisture (latent).
Sensible heat ratio (SHR)
Sensible ÷ total. Near 1.0 means little dehumidification; lower means a wetter duty.
Off-coil RH
A result of the chord geometry — typically ~90–95% for a wet coil, not a free input.
Apparatus dew point (ADP)
The coil surface condition you entered — the end of the process chord on saturation.
Contact / bypass factor
From BF = (T₂ − T_ADP)/(T₁ − T_ADP). Deep coils have a high contact factor.
Condensate
The rate of water wrung out — size the drain and trap for it.
A frost risk banner appears if the ADP is at or below freezing (the coil surface could ice up) — options are glycol protection, a DX defrost strategy or face-and-bypass control.

Psychrometrics — Desiccant Dehumidification

Psychrometrics Model a desiccant dehumidifier as an isenthalpic (or near-isenthalpic) process: moisture falls, dry-bulb rises along the enthalpy line.

When to use it

When you need deep dehumidification beyond what a chilled-water coil can reach, or want the leaving state and moisture-removal rate of a desiccant wheel / liquid desiccant contactor.

Inputs

Mode
State target — set leaving humidity ratio or RH. Duty & airflow — set moisture removal rate; leaving W follows from the mass balance.
Entering air
Dry bulb + second property, plus airflow through the wheel.
Desiccant efficiency ηd
100% = ideal isenthalpic (h2 = h1). Lower values add heat of adsorption above the enthalpy line.

How to use it

  1. Choose State target or Duty & airflow.
  2. Enter site altitude and the entering air condition + flow.
  3. Enter the leaving moisture target (or removal duty) and ηd.
  4. Press Calculate. Leaving dry-bulb, RH and moisture removed appear with the process line on the chart.

Reading the results

Leaving state
Hotter and drier than entering — dry-bulb is solved from the (near-)isenthalpic model.
ΔW / moisture removed
Humidity-ratio drop and the corresponding water removal rate at the entered airflow.
Adsorption Δh
Extra enthalpy above the ideal line when ηd < 100%.
Leaving air is usually too warm for direct supply — plan a downstream cooling coil or heat exchanger to trim dry-bulb without re-humidifying.

Psychrometrics — Heating & Humidification

Psychrometrics Two-stage winter path: sensible heating at constant moisture, then isothermal steam humidification at constant dry-bulb.

When to use it

When an AHU must both raise temperature and add humidity — the usual heating-coil then steam-humidifier sequence.

Inputs

Mode
State target — enter leaving dry-bulb and moisture. Duty & airflow — enter heating kW and steam rate.
Entering air
State 1 plus airflow.

How to use it

  1. Choose State target or Duty & airflow.
  2. Enter site altitude, entering condition and flow.
  3. Enter the leaving target (or heating duty + steam rate).
  4. Press Calculate. States 1 → X → 2 appear on the chart with coil and steam duties.

Reading the results

State X
After the heating coil: leaving dry-bulb at entering humidity ratio.
State 2
After steam: same dry-bulb as X, higher moisture.
Sensible / latent / total
Heating-coil duty, steam enthalpy to the airstream, and their sum.

Psychrometrics — Adiabatic Cooling

Psychrometrics Direct evaporative cooling along the constant wet-bulb line — dry-bulb falls, moisture rises, enthalpy nearly constant.

When to use it

For direct evaporative coolers, spray washers or evaporative media when you need the leaving state, water use and media effectiveness.

Inputs

Mode
State / effectiveness — set media ε or a leaving RH. Duty & airflow — set the required sensible cooling capacity.
Entering air
Hot/dry state plus airflow. Cooling potential is Tdb − Twb.

How to use it

  1. Choose mode and enter site altitude, entering condition and flow.
  2. Enter media effectiveness, leaving RH, or required cooling capacity.
  3. Press Calculate. Leaving state, ε, cooling effect and water evaporation appear with the wet-bulb process line on the chart.
Leaving dry-bulb cannot go below the entering wet-bulb — that is the thermodynamic limit (ε = 100%).

Psychrometrics — AHU Design

Psychrometrics Work backwards from the condition you need to deliver into the room. Give the required supply (off-unit) air; the tool mixes outdoor and return air, then derives the cooling/reheat or heating/humidification needed to get there.

When to use it

When you know the supply condition the space needs and want the coil duties that produce it — the inverse of specifying the off-coil condition and reading the result. It chains mixing → cool/reheat (summer) or heat/humidify (winter) into one staged process.

Inputs

Site Conditions
Altitude → derived barometric pressure.
Design season
Summer or Winter — loads typical OA / RA / supply defaults. The process path still follows the moisture balance (cool+reheat vs heat+humidify).
Outdoor Air — condition + Outdoor Air Flow
The fresh-air state and its volume flow (at the outdoor condition). The outdoor-air fraction of supply is derived from dry-air mass flows and shown in the results.
Return Air — condition
The air coming back from the space (used when outdoor air is less than 100% of supply).
Required Supply — condition + Supply Flow
The off-unit condition to deliver into the room, and the total supply volume flow.
Off-coil RH target (%)
Default 90% — same wet-coil leaving assumption as the Cooling Coil tool. Use 100% for idealised contact factor = 1. Applies when the supply is drier than on-coil (dehumidification).
Supply Fan — Position, SFP, Power
Optional fan heat gain. Blow-through sits before the coil (adds to coil duty); draw-through sits after the last coil/humidifier. Give the fan power directly (kW) or let it be estimated from Specific Fan Power (W per l/s). Leave Position on "No fan gain" to ignore it.

How to use it

  1. Set the site Altitude.
  2. Choose Summer or Winter (optional — sets typical defaults).
  3. Enter the Outdoor Air condition and outdoor air volume flow.
  4. Enter the Return Air condition.
  5. Enter the Required Supply condition and supply flow.
  6. For summer / dehumidification duties, confirm the off-coil RH target (90% default).
  7. Optionally set the fan position and power/SFP.
  8. Press Design. The derived stages, total cooling and total heating are listed and drawn on the chart; expand Design method & notes for the assumptions.

Reading the results

Each stage (mix, cool, reheat, humidify) is a row with its state and the duty/moisture change at that step. Totals give cooling duty, heating duty, and moisture added/removed. The derived outdoor-air fraction (%) is shown under the totals. A note under the totals states which path was used.

Process path is chosen from moisture: supply drier than on-coil → cool / dehumidify / reheat; supply wetter → heat then steam humidify; equal moisture → sensible cool or heat only. Frost is flagged when the off-coil temperature is at or below 0 °C.

Duct Sizing

Air Distribution Size a duct in all three shapes at once — circular, rectangular and flat oval — from one air volume and target, then build an index-leg pressure-drop run below. Updates are instant, no page reload.

When to use it

To pick a duct size for a given airflow to a velocity or friction-rate target, compare the three shapes side by side, and total the pressure drop along the worst-case (index) leg of a system.

Design Inputs (top panel)

Air Volume
The flow the duct must carry.
Size By
The basis for the initial size: Velocity or Friction Rate (Pa/m).
Target Value
The target velocity or friction rate to size to. All three shape columns are sized from these top inputs together.

Per-shape controls

Circular — Stock Size
Leave on "Auto" for the true calculated diameter, or pick a real Lindab stock diameter (its gauge and whether it's standard or special-order are shown).
Rectangular — Width / Height
Fully independent — change either with the +/− steppers and watch velocity, aspect ratio and friction rate respond. The padlock beside a dimension keeps it fixed when the top inputs change (e.g. a shallow ceiling void). Round to 25mm snaps both sides to a 25 mm grid.
Flat Oval — Major / Minor Axis
Step independently through Lindab's real stocked combinations only, so you can never land on an unmanufactured size (the fields are read-only; use the steppers).

Reading the shape results

Each column shows velocity, velocity pressure, friction rate and (for rectangular/flat oval) equivalent diameter. The traffic-light dots flag each figure: green in range, amber borderline, red out of range — the legend is above the columns. Rectangular also warns if the aspect ratio exceeds the 4:1 guide limit.

Index Leg — Pressure Drop (lower panel)

A spreadsheet-style builder for totalling the pressure drop along a run. Each row is sized independently — its own volume, shape and size — so a leg that steps down, changes shape and ends at a grille can be built piece by piece.

  1. Fill in the tinted top row (the composer): choose a Type — Straight, Fitting, Flex or Accessory — then its shape, volume, size and the type-specific field.
  2. A live preview (velocity / velocity pressure / friction-or-K / pressure drop) shows in that row before you commit it.
  3. Press + Add to commit it as a numbered row below. Repeat for each piece of the run.
  4. Edit any committed row's cells in place — the row's pressure drop and the running total update immediately.
  5. Optionally set a Safety Margin % to add a percentage to the total.
  6. Clear Table empties it; Export CSV downloads the run; the PDF report captures the leg table when rows exist.
Straight / Flex
Take a Length — pressure drop is length × friction rate (Flex adds a derating factor).
Fitting
Takes a Fitting from the dropdown; pressure drop is its K-factor × velocity pressure.
Accessory
Takes a free-text Description and a Manual ΔP you enter directly from your own manufacturer data (louvers, attenuators, dampers, grilles).
Fitting K-factors are indicative single-point values for preliminary sizing, not the full multi-parameter ASHRAE Ch.32 / CIBSE Guide C correlations — verify critical runs. Flex duct applies a ×1.5 planning friction derate. Flat-oval equivalent diameter uses ASHRAE Fundamentals Ch.21 / Heyt & Diaz (1975).

Unit Converter

Utilities Enter one value in one unit and see it in every other unit of its category at once — metric and imperial — with the conversion relationship shown beside each.

When to use it

Quick conversions across the 17 quantity categories an HVAC job throws up: length, area, volume, mass, force, pressure, temperature, speed, volume flow, mass flow, power, energy, time, angle, density, humidity ratio and enthalpy.

Inputs

Category
The quantity you're converting (changing it refreshes the unit list).
Value
The number to convert.
From unit
The unit your value is in, grouped Metric / Imperial / Other.

How to use it

  1. Pick the Category.
  2. Type the Value and choose the From unit — the results refresh automatically.
  3. Read the grouped table; your input row is highlighted, and each row shows the value plus the factor or formula (e.g. 1 mm = 0.0393701 in, or °F = °C × 9/5 + 32).
Temperature shows a below-absolute-zero warning if you enter an impossible value.

Pipe Sizing

Hydronics Flow from load or known flow; DN catalogue with traffic lights; circuit pressure-drop schedule with fittings and devices.

When to use

Size LTHW or CHW pipework: derive flow from a heating or cooling duty, or check a known flow against standard DN sizes. Then total the index-circuit pressure drop with straight runs, fittings/valves (K-factors), and manufacturer devices entered as direct Pa.

Inputs — Design (sizer)
Flow mode
Calculate from load — duty, ΔT and LWT give mass and volumetric flow. Flow known — enter flow directly in l/s (both l/s and m³/h are always shown).
Application
LTHW or CHW — duty context (traffic-light bands are the same for both).
Fluid
Water, or Hydratech Coolflow DTX / IGE (EG) / NTP (PPG) at a fixed catalogue % v/v.
LWT
Leaving water temperature; with ΔT this gives mean water temperature for fluid properties.
Material
Carbon steel (BS EN 10255), copper (BS EN 1057), or thin-wall stainless dairy tube (DIN 11850).
How to use — sizer
  1. Choose flow mode, application, fluid and pipe material.
  2. Enter load (or flow), ΔT and LWT, then click Calculate.
  3. Review the size table — green = ideal band (ΔP/L 200–300 Pa/m and per-DN velocity ideal); amber = CAPEX-heavy or CAPEX-light; red = out of range.
  4. Click a size row — pipe dimensions appear in the centre panel; flow and fluid data on the right.

Pipe System

Define the whole-system parameters first, then build the dynamic ΔP schedule. Fluid and duty come from Design Inputs; system type and lift sit at the top of this panel.

System type
Pressurised closed circuit — return / gravity cancels physical lift; pump head = friction only. Open tank — pump must lift to the open water surface; pump head = static lift + friction. Lift height is shown only for open tank.
Static lift height
Open tank only — vertical rise to the open water surface (m or ft).
Straight pipe
Length × friction rate (Pa/m) from Darcy–Weisbach at that row’s DN and flow.
Fitting / valve
Pick from the catalogue; ΔP = K × velocity pressure (½ρV²). K values are representative planning figures — not full CIBSE/Crane geometry tables.
Device (manual ΔP)
Enter a manufacturer pressure drop (coil, HX, etc.) directly in Pa.
Safety Margin %
Optional uplift on the running total (fitting uncertainty, future extensions).
Required pump head
Shown as Pa · kPa · bar (SI) or psi · in.wg · ft of fluid (IP).
  1. Set Design Inputs (fluid, duty) and Calculate so flow and fluid properties are known.
  2. In Pipe System, choose Pressurised closed circuit or Open tank; enter lift only if open.
  3. Add components in the tinted top row and click + Add; edit rows in place.
  4. Read required pump head at the bottom of the panel.
Traffic-light bands for the DN catalogue are documented under Reference → Pipe Sizing Design Limits. Velocity status uses per-DN bands (DN ≤ 50 max 1.5 m/s aligns with CIBSE Guide C Table 2.2; larger DN allow higher speeds) — not a flat 1.5 m/s limit on every size.
Full system volume (all pipework including branches, client-side volume, chiller volume, minimum chiller volume — for glycol purchase, buffer tanks and expansion vessels) is planned as a later stage.
