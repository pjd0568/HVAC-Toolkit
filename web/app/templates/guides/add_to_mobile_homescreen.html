Install HVAC Toolkit on your phone or tablet so it opens full screen from a Home Screen icon — the same feel as a native app. Use Safari on iPhone/iPad or Chrome on Android; other browsers often cannot complete the install.

After install, always launch from the Home Screen icon (not a browser bookmark) to get the standalone app chrome without the address bar.

iPhone & iPad (Safari)

  1. Open this site in Safari (not Chrome or an in-app browser).
  2. Tap the Share button (square with an upward arrow).
  3. Scroll the sheet and tap Add to Home Screen.
  4. Tap Add to confirm.
Safari → Share → Add to Home Screen → launch from the new icon.

Android (Chrome)

  1. Open this site in Chrome.
  2. Tap the menu ⋮ (top right).
  3. Tap Install app or Add to Home screen (wording varies by Chrome version).
  4. Confirm with Install or Add.
Chrome → ⋮ menu → Install app / Add to Home screen → launch from the icon.

What you get

The installed icon opens the toolkit in standalone mode: your SI/IP choice, drafts in the same tab, and the bottom dock on phones all work as in the browser — without the browser chrome. You can remove the icon anytime like any other Home Screen shortcut.

Tip: the top-bar link Add to mobile homescreen opens this guide from any page. Prefer Safari on Apple devices; Chrome on Android.
