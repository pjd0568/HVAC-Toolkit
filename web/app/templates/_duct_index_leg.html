Index Leg — Pressure Drop ?
Each row is sized independently — its own volume, shape and size — so a run that steps down, changes shape, or ends at a grille can be built piece by piece. Fill the entry row (type, size, length or fitting), check the live preview in the Pressure Drop cell, then press “Add”. Straight / flex preview shows friction rate (ΔP/L, Pa/m); fittings show the K-factor used for ΔP = K × VP. Fitting K-factors are indicative single-point values for preliminary sizing — not the full multi-parameter ASHRAE Ch.32 / CIBSE Guide C correlations. Flex-duct rows apply a ×1.5 planning derate to rigid friction. Accessory items take a manually entered pressure drop.
